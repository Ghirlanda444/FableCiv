# Music

Drop your Suno tracks here as MP3 (stereo, 128–192 kbps is plenty). The game looks for these exact file names
and simply stays silent for any that is missing, so you can add them one at a time:

| File | Plays when |
| --- | --- |
| `menu.mp3` | title screen and game setup |
| `ancient.mp3` | Ancient era |
| `classical.mp3` | Classical era |
| `medieval.mp3` | Medieval era |
| `renaissance.mp3` | Renaissance era |
| `industrial.mp3` | Industrial era |
| `modern.mp3` | Modern era |
| `atomic.mp3` | Atomic era |
| `information.mp3` | Information era |

Tracks loop and crossfade when the era changes. If an era has no track the game keeps playing the previous era's
track. Suggested length: 2–4 minutes each so the loop is not too obvious. Keep the loudness similar across tracks.

Music is switched on/off and its volume set from the in-game Menu; the setting is remembered on the device.
