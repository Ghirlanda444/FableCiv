# Translation glossary for Tiny Empires

Translate these game terms the same way every time within a language. Keep the untranslatable ones as they are.

| English | Meaning | Note |
| --- | --- | --- |
| Tiny Empires | the game | keep as is |
| Chibipedia | the in-game encyclopedia | keep as is |
| Inchibils, Inchibil | the wild raiders (invented word) | keep as is, decline the adjective form if the language needs it |
| empire / empires | a playable people (Rome, Japan…) | translate as "empire" |
| Free city / Free cities | independent single city with a leader | translate |
| Town / City / settlement | two kinds of settlement, and the generic word | translate consistently; Town is the small one |
| Knowledge | the science yield 🔬 | translate as the word for knowledge, never "science" |
| Heritage | the culture yield 🎭 | translate as heritage/legacy, never "culture" |
| Devotion | the faith yield 🕊️ | translate |
| Fame | the tourism yield 🧳 | translate |
| Ties | your standing with a free city | translate as "ties/bonds" |
| Patron / Kin / Partner / Acquaintance | tiers of Ties | translate |
| Spark | boost condition of a technology 💡 | translate |
| Insight | boost condition of a civic | translate |
| Mastery | permanent bonus after a Spark/Insight | translate |
| Pioneers, Militia, Pathfinder… | generic unit names | translate |
| Great People / Great Prophet… | translate | |
| Renown, Star Voyage, Conquest, Devotion, Legacy | the five victories | translate |
| HP, XP, Str | abbreviations | keep short |

Rules: keep emoji, numbers, percentages, HTML tags (`<b>`, `<br>`, `<small>`), and the characters `·` and `—` exactly. Many strings are fragments joined at runtime (for example "trained a", "more turns", "On the way to"): translate them literally and keep them short. Keep proper names of leaders, cities, wonders and historical peoples in their usual form in the target language. Never add explanations. Every key must be reproduced exactly as the JSON key.
